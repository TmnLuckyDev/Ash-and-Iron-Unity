## Kort

| Map-ID | Dimensioner (tiles) |
|---|---:|
| ashford-original | 88 × 40 |
| ashford-expanded | 176 × 80 |
| pinewatch-vale | 112 × 64 |
| ironbreak-pass | 144 × 72 |
| twinmere-basin | 160 × 88 |
| shattered-isles | 192 × 112 |

Map eksport indeholder de otte eksisterende terrain types, row-major tiles, bases og 36 repræsentative konfigurationer. Runtime seed påvirker symmetrisk spawn, ressourceplacering og AI-strategi. Shattered Isles' baseberegning bruger trigonometri i TypeScript; bake de statiske layouts til immutable table i stedet for at genberegne med Unity floats. Match-specifikke terrain ændringer skal være rollback-state. Eksakt generator skal porteres med deterministiske ties og source fixtures, også count 0 og max.

## Status på planlagte udvidelser

| Funktion | Status ved reference |
|---|---|
| Stabilitetsfase | Delvis. Native startup/reconnect, delta, save og tests findes. Fuld protocol-version gate, robust korrupt save-håndtering og vedvarende room recovery i Render mangler. `solo-runtime` sender resetSession ved ugyldigt save, `solo.ts` kalder leave og kan slette eget slot. Nyt save skal bevare original ved fejl. |
| AI Overhaul | Delvis. Ekspansionsstrategi betyder flere workers og varierede timings, ikke fuld langtids multi-base AI. `build` har ingen settlement-plan og `think` forsker primært første Weapons/Armor plus Fortress. Rekrutterings-/angrebsbølger har små faste størrelser. Fuld skalerende økonomi, sen research, rekonstruktion og 500-pop test er ny udvikling. |
| Retreat | Findes som klientgenvej, udsteder almindelig Move til gruppens rally eller egen startbase. AI har eget Elf retreat. En egentlig retreat stance er planlagt. |
| Formationer / defence | Implementeret med Line/Compact/Spread, automatic defense/leash. |
| Patrol / Hold Position / Guard | Ingen player order i `Order` eller validering. AI's interne naval patrol og `halt` er forskellige. Planlagt. |
| Waypoints / QueueOrder / Combat Stances / Attack Priority | Ikke generelle spillervalg. Intern path waypoints findes. Planlagt. |
| Auto-replenish / økonomisk reservation for template | Manuel Replenish med allerede queued popreservationer og automatisk recruit assignment findes. Ingen løbende auto-replenish eller reserveret template-bank. Planlagt. |
| Transport multi-trip | Transfer i én bølge findes; automatisk pendulfart er planlagt. |

Paritetsporten skal først reproducere koden ovenfor. Planlagte features skal være slukket i reference-mode og testes særskilt. Eksisterende browserudgave må ikke få nye gameplayregler som sideeffekt af denne migration.
